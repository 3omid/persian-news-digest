# Persian News Digest — خلاصه خودکار اخبار

اسکریپتی که هر روز خودکار اجرا می‌شه، از چند منبع خبری RSS اخبار رو در ۵ دسته جمع‌آوری می‌کنه،
با Claude API خلاصه/مقایسه/تحلیل می‌کنه، یک گزارش HTML گرافیکی و راست‌چین می‌سازه، و (اختیاری)
به تلگرام می‌فرسته.

## دسته‌بندی‌ها
- قیمت دلار آمریکا/کانادا (نمودار + دلار بازار آزاد ایران) + طلا + کریپتوکارنسی
- اخبار اقتصادی + پیش‌بینی اقتصادی
- سیاسی داخلی
- سیاسی خارجی
- ورزشی
- اخبار جنگ ایران
- + یک بخش تحلیل سیاسی کلی
- + مهم‌ترین اخبار هفته (هر جمعه) و ماه (اول هر ماه میلادی) به‌صورت خودکار اضافه می‌شه

## ⏱️ زمان‌بندی و اجرای دستی
- اسکریپت هر **ساعت** خودکار اجرا می‌شه (نه فقط روزی یک‌بار).
- اگه خبر جدیدی نباشه، **هیچ گزارشی ساخته و ارسال نمی‌شه** — یعنی اسپم نمی‌شی.
- هر وقت خواستی خودت دستی بگیری: برو به تب **Actions** تو گیت‌هاب → workflow
  «Persian News Digest» → **Run workflow** → می‌تونی یک دسته خاص (مثلا فقط «ورزشی») یا
  همه رو انتخاب کنی، و می‌تونی «force» رو فعال کنی تا حتی بدون خبر جدید هم گزارش بسازه.
- محلی هم می‌تونی بگیری:
  ```bash
  python main.py --category ورزشی --force
  ```

## 💰 بخش اقتصادی: ارز، طلا، کریپتو
- نرخ USD/CAD رسمی (نمودار ۷ روزه) + دلار بازار آزاد ایران
- طلا: نیاز به یک **API Key رایگان** از [goldapi.io](https://www.goldapi.io) داره (ثبت‌نام رایگان،
  پلن رایگانش کافیه). بعد از گرفتنش، به‌عنوان سیکرت گیت‌هاب با نام `GOLD_API_KEY` اضافه‌ش کن.
- کریپتو: از CoinGecko میاد و کاملا رایگان و بدون کلید — کوین‌های پیگیری‌شده رو تو `config.py`
  (متغیر `TRACKED_COINS`) عوض کن.
- **مهم:** گزارش کریپتو فقط داده و روند قیمت رو می‌ده (بیشترین رشد/افت، اخبار مرتبط) و عمدا
  هیچ‌وقت نمی‌گه «بخر» یا «بفروش» — این یک تصمیم مالی شخصیه که باید خودت با اطلاعات موجود
  بگیری، نه چیزی که یک اسکریپت خودکار باید بهت دیکته کنه.

## ⚠️ قبل از اجرا حتما این کار رو بکن
منابع RSS تو `config.py` رو **تست کن**. چون این پروژه تو یک محیط بدون اینترنت ساخته شده،
بعضی آدرس‌ها (مخصوصا ایرنا) ممکنه دقیق نباشن. اولین اجرا رو لوکال روی کامپیوترت
بگیر و لاگ‌ها رو ببین — هر منبعی که "جواب نداد" نوشت، آدرسش رو با یک جستجوی سریع پیدا کن
و در `config.py` جایگزین کن.

**دو منبع مشخصا با برچسب `TO VERIFY` علامت خوردن و حتما نیاز به بررسی دستی دارن:**
- **ایران اینترنشنال فارسی**: آدرس انگلیسی‌ش (`iranintl.com/en/feed`) تایید شده، ولی
  آدرس فارسی (`iranintl.com/fa/feed`) رو حدس زدم. اگه کار نکرد، برو به `iranintl.com/fa`
  و دنبال آیکون RSS بگرد یا با جستجو "iranintl فارسی rss" پیدا کن.
- **صدای آمریکا فارسی (VOA)**: صفحه `ir.voanews.com/rssfeeds` لیست فیدهاست ولی آدرس دقیق
  XML هر بخش رو باید از داخل اون صفحه (کلیک راست روی آیکون RSS → Copy Link) بگیری.

این دو منبع عمدا انتخاب شدن چون **دیدگاه خارج از کشور** می‌دن (در مقابل ایرنا که دیدگاه
رسمی داخل ایرانه) — Claude تو تحلیل هر خبر، این تفاوت دیدگاه رو تو بخش "مقایسه منابع" میاره.

## نصب و اجرای محلی (تست اولیه)
```bash
cd persian_news_digest
pip install -r requirements.txt

export ANTHROPIC_API_KEY="sk-ant-..."
# اختیاری برای ارسال تلگرام:
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."

python main.py
```
گزارش نهایی تو پوشه `output/latest.html` ساخته می‌شه — با مرورگر بازش کن.

## راه‌اندازی اجرای خودکار (GitHub Actions — رایگان)
1. یک ریپازیتوری خصوصی (Private) جدید تو گیت‌هاب بساز و این فایل‌ها رو push کن.
2. تو تنظیمات ریپو برو به: `Settings → Secrets and variables → Actions → New repository secret`
   و این سیکرت‌ها رو اضافه کن:
   - `ANTHROPIC_API_KEY`
   - `GOLD_API_KEY` (رایگان از goldapi.io - برای بخش طلا)
   - `TELEGRAM_BOT_TOKEN` (اگه می‌خوای نتیجه رو تو تلگرام بگیری)
   - `TELEGRAM_CHAT_ID`
   - `NETLIFY_AUTH_TOKEN` و `NETLIFY_SITE_ID` (اختیاری - فقط اگه بخوای علاوه بر GitHub Pages، رو Netlify هم داشته باشی)
3. فایل `.github/workflows/daily-digest.yml` از قبل آماده‌ست و **هر ساعت** اجرا می‌شه (قابل تغییر
   با ویرایش خط `cron`). از تب **Actions** هم می‌تونی دستی اجراش کنی و یک دسته خاص انتخاب کنی.
4. هر بار که اجرا می‌شه، گزارش HTML هم به‌عنوان **Artifact** قابل دانلوده، هم (در صورت تنظیم)
   به تلگرام فرستاده می‌شه.

## انتشار خودکار روی GitHub Pages (لینک وب دائمی - رایگان، بدون هیچ کلید اضافه)
هر بار workflow اجرا بشه، گزارش جدید خودکار روی یه صفحه‌ی وب متعلق به خودت (میزبانی‌شده توسط
خود گیت‌هاب، رایگان) پابلیش می‌شه. برخلاف Netlify، هیچ توکن یا کلید اضافه‌ای لازم نداره -
فقط یه بار باید فعالش کنی:

1. تو ریپازیتوری‌ت برو **Settings → Pages** (تو منوی سمت چپ).
2. زیر «Build and deployment»، تو قسمت **Source**، گزینه‌ی **GitHub Actions** رو انتخاب کن
   (نه «Deploy from a branch»).
3. همین! از اجرای بعدی workflow، یه لینک به این شکل فعال می‌شه:
   `https://<یوزرنیم‌گیت‌هابت>.github.io/<اسم-ریپو>/`
   (مثلا اگه یوزرنیمت `3omid` و اسم ریپو `persian-news-digest` باشه:
   `https://3omid.github.io/persian-news-digest/`)
4. لینک دقیق رو هم می‌تونی تو تب **Actions**، داخل همون اجرای موفق، بالای لاگ در قسمت
   «Deploy to GitHub Pages» پیدا کنی.

اگه قبلاً یه چیزی به اسم Netlify یا تنظیمات دیگه‌ای رو دستی تغییر داده بودی و به‌هم ریخته،
نگران نباش - این تنظیمات (Settings → Pages) کاملاً جدا و مستقل از هر چیز دیگه‌ایه که قبلاً
دست‌کاری کردی؛ فقط همین یک مرحله بالا کافیه.

## ساخت ربات تلگرام (اختیاری ولی توصیه می‌شه)
1. تو تلگرام با [@BotFather](https://t.me/BotFather) چت کن و `/newbot` بزن → یک توکن می‌گیری.
2. برای `TELEGRAM_CHAT_ID`: به ربات `@userinfobot` پیام بده تا آی‌دی عددی خودت رو بگیری.

## ساختار فایل‌ها
```
config.py            تنظیمات: منابع RSS، نرخ ارز، Claude، تلگرام
fetch_news.py         گرفتن RSS + جلوگیری از خبر تکراری (SQLite)
fetch_rates.py         نرخ USD/CAD (بانک مرکزی کانادا) + دلار بازار آزاد ایران
analyze.py            تحلیل با Claude API (خلاصه، مقایسه منابع، پیش‌بینی اقتصادی، تحلیل سیاسی)
generate_report.py    ساخت گزارش HTML گرافیکی + نمودار
send_telegram.py      ارسال گزارش به تلگرام
main.py               ارکستریتور اصلی
```

## مراحل بعدی پیشنهادی
- اضافه کردن منابع بیشتر برای هر دسته (هرچی منبع بیشتر، مقایسه دقیق‌تر)
- اضافه کردن ایمیل به‌جای/علاوه‌بر تلگرام (با `smtplib`)
- ساخت یک بات تلگرام تعاملی که بشه ازش خبر یک حوزه خاص رو درخواست کرد
- این پروژه یک نمونه خوب برای پورتفولیوی IT/سایبرسکیوریتیه — می‌تونی بگی:
  "Built an automated news aggregation & AI-analysis pipeline with scheduled CI/CD (GitHub Actions),
  RSS ingestion, deduplication (SQLite), and Claude API integration for summarization and analysis."

## 🆕 تغییرات آخر (بر اساس فیدبک تو)
- **۱۰ عنوان مهم در هر بخش**: گزارش همیشه تا ۱۰ خبر برتر هر دسته رو نشون می‌ده (نه فقط خبرهای کاملا تازه)
  تا هیچ بخشی خالی نمونه. خبرهای واقعا جدید (در ۱ ساعت اخیر) با نشان سبز «جدید» مشخص می‌شن.
- **تاریخ دوگانه**: زیر هر خبر، تاریخ شمسی و میلادی با هم نمایش داده می‌شه (مثلا «۱۳ شهریور ۱۴۰۵ | 2026-09-04»)
  - بدون نیاز به کتابخانه خارجی، تبدیل تو فایل `jalali.py` انجام می‌شه.
- **دکمه «تحلیل» زیر هر خبر**: با کلیک، یک تحلیل کوتاه مخصوص همون خبر باز می‌شه (پیش‌محاسبه‌شده توسط
  Claude موقع ساخت گزارش - نیازی به اتصال اینترنت لحظه‌ای نداره، پس رایگان و سریع باز می‌شه).
- **چند ارز با نمودار روزانه/هفتگی/ماهانه**: الان USD/CAD, EUR/CAD, GBP/CAD رو داریم که هرکدوم
  ۳ نمودار (روزانه، هفتگی، ماهانه) دارن. لیست ارزها تو `config.py` (`TRACKED_CURRENCIES`) قابل تغییره -
  هر کد ارز سه‌حرفی که تو Bank of Canada Valet API هست رو می‌تونی اضافه کنی.
- **کانال‌های تلگرام**: کانال‌هایی که تو اسکرین‌شاتت بودن (وحید هدلاین، چرک‌نویس مدیا، هدف آزادی،
  IndyPersian، شب‌نامه، مملکته، وحید آنلاین، Iranwire) به `config.py` اضافه شدن، از طریق پل رایگان
  RSSHub. **باید یوزرنیم دقیق هرکدوم رو خودت پر کنی** (تو تلگرام: باز کن کانال → روی نامش بزن →
  یوزرنیمی که با @ شروع می‌شه رو کپی کن) و جای `PLACEHOLDER_...` تو `TELEGRAM_CHANNELS` بذار.
  اگه rsshub.app کند بود، می‌تونی یک نمونه رایگان خودت دیپلوی کنی (مستندات: docs.rsshub.app/deploy).
- **فونت**: فونت Estedad (رایگان، متن‌باز - SIL OFL) به‌صورت سلف‌هاست از داخل خود مخزن
  (`assets/fonts/`) لود می‌شه، نه از یک دامنه‌ی خارجی مثل گوگل‌فونت - این‌طوری رو هر
  دستگاه/شبکه‌ای (از جمله آیفون که با گوگل‌فونت مستقیم مشکل داشت) دقیقا یک فونت نمایش داده می‌شه.
- **بخش‌ها بصری از هم جدا شدن**: هر دسته خبری الان رنگ و آیکون مخصوص خودش رو داره (اقتصادی آبی،
  سیاسی داخلی بنفش، سیاسی خارجی سبز، ورزشی نارنجی، جنگ قرمز) تا در نگاه اول قابل تشخیص باشن.

- نمودارها دیگه به‌صورت پیش‌فرض نمایش داده نمی‌شن - فقط دکمه «📊 نمودار» رو بزنی، یک پنجره بزرگ
  باز می‌شه با ۳ تب «روزانه / ماهانه / سالانه» - همه‌چیز فقط با CSS خالص کار می‌کنه (بدون جاوااسکریپت)
  تا روی هر مرورگری بدون مشکل کار کنه
- رنگ سبز/قرمز واضح‌تر برای نمایش رشد/افت (مثل tgju.org) + اعداد با ارقام فارسی
## 💴 نمایش همه ارزها به تومان
- بالای گزارش، دو کارت بزرگ برای **دلار آمریکا** و **دلار کانادا** به تومان، بر اساس آخرین نرخ
  بازار آزاد ایران (تومان دلار) که خودت دادی.
- بقیه ارزها (یورو، پوند، ین، یوان) هم به تومان تبدیل می‌شن، با همین فرمول:
  `تومان_ارز = (ارز/CAD رسمی) × (تومان_دلار ÷ USD/CAD رسمی)`
- **محدودیت مهم**: نمودار روزانه/ماهانه/سالانه هر ارز همچنان بر اساس نرخ رسمی CAD رسم می‌شه، نه تومان -
  چون منبع نرخ بازار آزاد ایران فقط لحظه فعلی رو می‌ده، نه تاریخچه. این تو خود گزارش هم زیر عنوان
  هر نمودار یادآوری شده تا گمراه‌کننده نباشه.

## ⚠️ درباره صحت داده‌های پیش‌نمایش
همه‌ی خبرها، قیمت‌ها و نمودارهای پیش‌نمایش‌هایی که تا الان دیدی **کاملا ساختگی/نمونه** هستن -
چون محیطی که این پروژه توش ساخته می‌شه به اینترنت زنده وصل نیست. اسکریپت واقعی (`main.py`) وقتی
با کلید API واقعی روی گیت‌هاب اجرا بشه، همه‌ی این داده‌ها رو live از منابع واقعی (RSS، بانک مرکزی
کانادا، tgju.org، CoinGecko) می‌گیره. اولین اجرای واقعی رو حتما قبل از اعتماد کامل بررسی کن.

  جدول کامل طلا و سکه ایران (۱۸ عیار، ۲۴ عیار، سکه‌ها) که از قبل داشتیم کافیه.

## 🆓 استفاده از API رایگان (Gemini) به‌جای Claude
پروژه الان به‌صورت پیش‌فرض از **Gemini** (رایگان و دائمی، بدون کارت بانکی) استفاده می‌کنه:

1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) و با اکانت گوگل وارد شو
2. **Create API Key** رو بزن - نیازی به هیچ پرداختی نیست
3. کلید رو به‌عنوان سیکرت گیت‌هاب با نام `GEMINI_API_KEY` اضافه کن
4. تمام! `MODEL_PROVIDER=gemini` از قبل تو workflow تنظیم شده

**درباره سوالت راجع به هزینه Anthropic**: اون ۵ دلار *ماهانه نیست* - یه شارژ یک‌بارمصرفه که فقط
به اندازه مصرف واقعی کم می‌شه و طبق قوانین رسمی Anthropic تا **یک سال** اعتبار داره (نه یک ماه).
ولی چون نمی‌خواستی هزینه‌ای بدی، الان پیش‌فرض پروژه کاملا رایگانه (Gemini).

اگه بعداً خواستی کیفیت تحلیل رو بالاتر ببری (Claude معمولاً تحلیل ظریف‌تری می‌ده)، فقط کافیه:
- سیکرت `ANTHROPIC_API_KEY` رو هم اضافه کنی
- تو فایل workflow، `MODEL_PROVIDER: gemini` رو به `MODEL_PROVIDER: anthropic` تغییر بدی

هر دو مسیر از قبل تو کد (`analyze.py`) پیاده‌سازی شده و کار می‌کنه.
